# Connected GRC source projection matrix

| Source | Projectable collections |
| --- | --- |
| Findings/CAPA | `findings` |
| Incidents | `incidents` |
| Business Continuity | `plans`, `exercises`, `gaps` |
| Policy | `documents`/`policies`, `versions` |
| Risk Appetite & KRI | `appetites`, `measurements`, `breaches`, `scenarios` |
| Regulatory Intelligence | `sources`, `changes`, `impacts` |
| Third Party Risk | `vendors`, `assessments`, `findings` |

Collections outside this matrix are auxiliary API data and do not create Connected GRC enterprise nodes in the current adapter contract.

# Searchable Connected GRC gaps

The Gaps view now has its own search and source-module filters. Search covers record IDs/codes/titles, localized module and relationship labels, unresolved reference values and ambiguous target candidates. Filtering retains source order and exact correction navigation.

Matching/total counts remain visible; the global completeness percentage and Gaps tab count retain the full loaded scope. A filtered empty result explicitly says that no records match; it never claims that the organization has no missing relationships. Existing partial-source notices are preserved.

Unresolved references render 20 at a time with a Show more action. Search covers every loaded reference, including those beyond the render budget, and changing filters resets both gap and reference display limits. Existing compact styles, mobile wrapping and TR/EN labels are reused.

Verification includes source/candidate searches, Turkish casing, module isolation, 83-reference search and browser checks for 25 references, incremental display, exact reference search, empty-state honesty, clear and mobile layout.

# Connected GRC workbench

Approved direction (11 November 2026): record-centred connection desk, with impact inspection and gap completion sharing the same selected record. Preserve the existing palette, TR/EN, permissions, source diagnostics, exports and assurance operations.

Operators can inspect typed direct/indirect relationships, understand their source, and complete supported core-record relationships without leaving the workbench. Enterprise lifecycle records keep their existing controlled workflows. Missing data is distinct from missing relationships. Connection coverage is never presented as compliance or control effectiveness.

Acceptance: bounded, cycle-safe traversal; exact source navigation and return; stable selection across views; source failures remain visible; unique affected-record counts; typed canonical links; stale writes and unavailable targets rejected; unlink does not delete records or bypass mandatory fields; atomic link history; read-only users cannot mutate; useful empty/partial states; keyboard, narrow viewport, light/dark and TR/EN verification.

Delivery scope: relationship desk, accessible diagram/list, impact paths, unified gap queue, core relation editor and draft continuity-plan BIA linkage. AI suggestions, saved snapshots and bulk changes are deferred. No new graph database or external service. Rollback is a code revert; additive relationship history remains available and existing records retain their canonical links.

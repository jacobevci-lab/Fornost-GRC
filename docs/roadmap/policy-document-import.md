# Import an existing policy document

A policy owner can select a Word DOCX or text-based PDF from the Policy Center, review and edit the extracted text, and save a first draft or the next draft of an existing policy. Preserve the uploaded file on the exact version and keep approval, publication, attestation and existing versions under the normal lifecycle. Verify writer access, validation, duplicate/retried writes, failed transfers and signed-out download access. Use real documents in browser QA. Scanned PDFs need a searchable text layer.
